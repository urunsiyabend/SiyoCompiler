## Review focus

- Duplicate ids across files, self-dependency, unknown dependency, wrong types,
  duplicate JSON keys, BOM, deep nesting, huge numbers, control characters.
- Same plan whatever the file or argument order.
- A deep chain in both directions on both backends.
- `BlockExit` must not change `try`, spawn or actor behaviour.
- A void block arm now has no value: a match used as a value must still report
  mixed arms rather than verify-fail.
