# LogScope Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship LogScope (JSONL log summariser/filter/reporter) as a Siyo project, and fix the compiler/stdlib gaps it exposes, with parity regression tests and a release-ready version bump.

**Architecture:** Compiler fixes land first, each driven by a failing JUnit parity test. The app is a `siyo.toml` project of six single-purpose modules; it is tested by Siyo unit tests and by a JUnit end-to-end test that runs the CLI through both backends against golden fixtures.

**Tech Stack:** Java 21, Maven, ASM (compiler); Siyo 0.7.x (app); JUnit 5.

**Spec:** `docs/superpowers/specs/2026-10-08-logscope-design.md`

## Global Constraints

- Work only in this worktree; no push/merge/tag/publish.
- Every behaviour change in the compiler/stdlib has a JUnit test asserting identical compiled and interpreted output.
- No Java workaround in the app for a gap that is fixed in the compiler; a deferred gap may be worked around in the app only with a comment pointing at its PAIN_POINTS id.
- Version: 0.7.1 if only bug fixes land, 0.8.0 if any additive feature lands.
- Reports are deterministic (stable ordering; no wall-clock time in output).

## Review Focus

- A JSONL line that is valid JSON but not an object, or lacks `level`/`msg` → counted as invalid with a reason, never a crash. (Task 4 test `nonObjectLineIsBad`, `missingLevelIsBad`.)
- Blank lines and a trailing newline → skipped, not counted invalid. (Task 4 test `blankLineIsSkipped`.)
- A message containing `<script>`/quotes → escaped in HTML and correctly quoted in JSON. (Task 6 test `htmlEscapesMessage`; e2e fixture `mixed.jsonl` contains one.)
- Missing input file → exit code 2 with a one-line message on stderr, both backends. (Task 7 e2e `missingFileExitsTwo`.)
- Unknown flag / missing flag value → exit 1 with usage. (Task 3 tests `unknownFlagIsUsageError`, `flagWithoutValueIsUsageError`.)
